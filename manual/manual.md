## How to Defuse Bombs
The bomb will explode if the timer runs out or you make too many mistakes. Each mistake is counted as a strike. The only way to safely defuse the bomb is to disarm all the modules before the timer runs out.

### Modules
A bomb will include a number of modules you need to disarm. Each module has its own rules for how to disarm it. Modules can be disarmed in any order. Instructions for disarming each module can be found later in this manual.

### Strikes
You get a strike when you solve a module wrongly. You have three strikes (or mistakes) before the bomb explodes. Strikes are shown next to the timer. The timer will also speed up a bit with each strike.

### Gathering Information
To disarm some modules, you need extra information, such as the serial number or the ports. These can typically be found on the sides of the bomb. See the rest of this manual to learn how to identify them.

# Section 1: Modules
Each module has an LED in its top right corner. When the LED is lit green, the module has been disarmed.

All modules must be disarmed to defuse the bomb.

# Module 1: Wires
Wires is one of the simplest modules to disarm. Go down the list and follow the first rule that applies.

* A wire module has 3-6 wires.
* Wires are ordered from top to bottom.
* There are 6 colors of wire (blue, green, red, yellow, pink, and black).

### **3 Wires:**
1. If there is a blue wire, cut the last wire.
2. If there is no red wire, cut the first wire.
3. Otherwise, cut the middle wire (the second one).

### **4 Wires:**
1. If there is a yellow wire, cut the third wire.
2. If there is a green wire, cut the second wire.
3. If there are no red wires, cut the fourth wire.
4. Otherwise, cut the first wire.

### **5 Wires:**
1. If exactly two wires are the same color, cut both of them.
2. If there is a yellow wire, cut the fifth wire.
3. If the second wire is blue, cut the second wire.
4. If the last wire is black and the last digit of the serial number is odd, cut the fourth wire.
5. Otherwise, cut the first wire.

### **6 Wires:**
1. If there are no pink wires and the first digit of the serial number is even, cut the sixth wire.
2. If there are one or more pink wires and the last digit of the serial number is even, cut the second wire.
3. If there are two or more blue wires, cut the third wire.
4. If the bomb has two or more batteries and there is a yellow wire, cut the fifth wire.
5. If the last wire is green, cut the fourth wire.
6. Otherwise, cut the first wire.

# Module 2: Button
The button is also very simple. Press the main button the number of times the rules say, then click the white Confirm button. The main button comes in blue, red, and green, and it may show a word or no text at all.

Go down the list and follow the first rule that applies.

### **Disarming It:**
1. If the button is red and says "Press", press it once, then click Confirm.
2. If the button is blue, just click Confirm.
3. If the button says "Nothing" and the bomb has a Double A battery, press it twice, then click Confirm.
4. If the button has no text, press it four times, then click Confirm.
5. If the bomb has a USB-C port, press it once, then click Confirm.
6. If the button is green, press it three times, then click Confirm.
7. Otherwise, press it once, then click Confirm.

# Module 3: Timer
This module is solved by reading the bomb's timer. Match the time on the timer to a color, then point the gauge at that color.

The gauge has five colored sections, from green on the left to red on the right.

1. Read the time shown on the bomb's timer.
2. Find that time in the table below to get the color.
3. Click that color on the gauge to point the needle at it.
4. Click Confirm.

The timer keeps running while you work. The time that counts is the time shown when you click Confirm.

| Time | Color |
| --- | --- |
| 5:00 - 4:01 | Green |
| 4:00 - 3:01 | Light green |
| 3:00 - 2:01 | Yellow |
| 2:00 - 1:01 | Orange |
| 1:00 - 0:01 | Red |

# Module 5: Mathematics
The display shows two pairs of letters with a symbol between them. Each pair of letters is a two-digit number. Solve the equation and enter the answer.

1. Use the letter table to turn each letter into a digit. This gives you two two-digit numbers.
2. Use the symbol table to turn the symbol in the middle into an operation.
3. Solve the equation, enter the answer, and click Confirm.

### **Letter Table:**
| A | B | C | D | E | F | G | H | I |
|---|---|---|---|---|---|---|---|---|
| 3 | 6 | 7 | 1 | 4 | 9 | 5 | 8 | 2 |

### **Symbol Table:**
| Symbol | `[]` | `{}` | `()` | `<>` |
|---|---|---|---|---|
| Operation | + | − | × | ÷ |

**Example:** The display shows `AB {} DE`. This translates to 36 − 14, which equals 22. So the answer is 22.

# Module 9: Direction
The defuser is shown a compass with a needle. Each click on the compass turns the needle to the next direction (north, east, south, or west). The defuser needs your help to find the direction the needle must point at.

Go down the list and follow the first rule that applies. Tell the defuser which direction to point the needle at. When the needle points the right way, the defuser clicks Confirm.

1. If the bomb has an XLR port, point the needle west.
2. If the bomb has more than two batteries, point the needle east.
3. If the second digit of the serial number is odd, point the needle west.
4. If the needle was pointing north when the bomb started, point it south.
5. Otherwise, point the needle north.
